**Enterprise UI Playground is a catalogue of real Flutter UI flows** — complete, multi-screen journeys such as logging in, checking out, sharing content or onboarding a new user. Every flow runs live in your browser, so you can tap through it exactly as a user would before you decide to use it.

## What's a flow?

A flow is a small, self-contained Flutter feature: one or more screens, the navigation between them, and the state they share. Flows are grouped into six categories:

- **Account Management** — logging in, editing a profile, resetting a password, logging out, deleting an account.
- **Commerce & Finance** — listings, carts, ordering, booking, refunds, transfers, subscriptions and redeeming.
- **Content** — creating, editing, uploading, searching and filtering content, plus recording, scanning and watching media.
- **Misc** — setting up, connecting accounts, verifying, dark mode, switching views and toggles.
- **New User Experience** — tutorials, creating an account and onboarding.
- **Social** — inviting, chatting, calling, commenting, sharing, following, reviewing, blocking and reporting.

Browse them all on the [Flows](/flows) page.

## Live in your browser

Each flow page runs the actual Flutter code, compiled for the web, inside a phone, tablet or laptop frame. Switch devices to check responsive layouts, restart the flow to begin again, and toggle light or dark mode — nothing is a screenshot or a video.

## Read the source

Every flow page has a **Code** tab with the Dart source for that flow: the files inside the flow's folder and any shared files it imports. See [Using a flow](/docs/installation) to bring one into your own Flutter app.

## Built with Flutter

The flows are written in [Flutter](https://flutter.dev) with a small number of well-known packages. They are designed to be read, copied and adapted rather than installed as a library.
