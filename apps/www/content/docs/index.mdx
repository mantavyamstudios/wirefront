**Wirefront is a catalogue of 200 responsive, ready-to-wire UI screens** built on [shadcn/ui](https://ui.shadcn.com) with [Base UI](https://base-ui.com) and Tailwind CSS v4. Every screen runs live in your browser, so you can click through it before you install it with the shadcn CLI.

## What's a screen?

A screen is one self-contained page or panel: a pricing table, a members list, a sign-in form, an AI chat. Each ready-to-wire screen is a folder of three files:

- **`view.tsx`** — the screen itself: props in, UI out. No data, no fetching, no router.
- **`schema.ts`** — zod schemas, the screen's types and its API contract.
- **`fixtures.ts`** — demo data that satisfies the schema, for tests and mocks.

Screens come in 23 kinds, grouped six ways:

- **Shells** — layouts: app frames and navigation.
- **Accounts** — auth and onboarding, settings, profile, pricing.
- **Data** — dashboards, tables, charts, filters.
- **Activity** — cards, timelines, calendars, threads and comments.
- **Interaction** — forms, modals, toasts and banners, tours and coachmarks, empty states.
- **Products** — apps, AI and agents, dev tools, personal, commerce.

Browse them all on the [Screens](/screens) page.

## Live in your browser

Each screen page runs the real React component inside a phone, tablet or laptop frame. Switch devices to check the responsive layout, replay the screen to begin again, and toggle light or dark mode. Nothing is a screenshot or a video.
